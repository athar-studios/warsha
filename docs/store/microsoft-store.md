## Long description

```text
Warsha (ورشة) is an Arabic-first AI software factory for Windows. Give it one line of idea
and a team of twelve AI agents takes it through research, requirements, design, code, review,
security, release and launch — stopping at four gates so you approve what happens next.

Every run is visible. The Simple mode shows the team as a sidebar of agents with a plain-language
summary of what each one did, and approval cards for the gates that are waiting. The Advanced mode
shows the raw material: live event stream, diffs, file tree, task board, skill and MCP
configuration, and per-role cost.

Warsha does not sell you a model. Add your own provider — an OpenAI or Anthropic API key, a
DeepSeek or OpenRouter key, or a local Ollama model with no account at all. Keys go to the Windows
Credential Manager and never appear in configuration files, logs, or command output.

Nothing is published, posted, pushed, or released without you. Agents draft; the owner approves.
No agent can approve a gate, and there is no automatic path around one.

Built for Arabic first: the interface, the artifacts, and the agent prompts all work in Arabic,
with full right-to-left layout and an English switch.

Warsha is local-first. Your project state, artifacts, and history stay on your PC. No telemetry,
no analytics, no account required.
```

## Privacy note

Warsha is local-first and collects nothing. There is no telemetry, no analytics endpoint, and no
account. Prompts and artifacts are sent only to the model provider the user configures, under the
user's own API key. Credentials live in the Windows Credential Manager. The optional relay server
forwards end-to-end encrypted frames and cannot read them. A hosted privacy policy URL is required
before submission and is a human-only step — it is not yet published.
