# Warsha Documentation

**Warsha (ورشة)** — An Arabic-first AI software factory that automates the full development lifecycle from idea to production.

## Overview

Warsha is an open-source AI software factory designed with Arabic as the primary language. It orchestrates AI agents through a structured pipeline with gates, artifacts, budgets, and human approvals.

## Key Features

- **Arabic-first** — Full RTL support, Arabic canonical strings, ICU MessageFormat
- **Structured pipeline** — 14 stages with 4 gates (A, B, C, D)
- **Multi-provider** — OpenAI, Anthropic, Ollama, custom OpenAI-compatible
- **Human-in-the-loop** — Gate approvals with device confirmation
- **Budget enforcement** — Per-project and per-role cost tracking
- **Secure pairing** — E2E encrypted mobile/desktop communication
- **GitHub integration** — Repos, issues, PRs, checks, automated merges
- **Coding backends** — Goose (default), OpenHands, Claude Code, Codex, Gemini, Cursor
